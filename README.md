# williamchuang.github.io

Source of [logarcheon.com](https://logarcheon.com), the research site of William Huanshan Chuang, founder of Logarchéon Inc.

## Contents

- Research pages in mathematics, theoretical physics, machine-learning architecture, Indo-Pacific security and Sino-Catholic history
- Papers, lecture notes and slides (`files/`)
- CV and teaching materials

## Build

A Jekyll site (`_config.yml`, `_layouts/`, `_includes/`, `_posts/`), built and deployed to GitHub Pages by the workflow in `.github/workflows/pages.yml`.

To preview locally:

```bash
gem install jekyll jekyll-feed jekyll-seo-tag
jekyll serve
```

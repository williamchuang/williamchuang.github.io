Core thesis

Atiyah’s method repeatedly turns geometry into topology, topology into analysis, analysis into index formulas, and index formulas back into geometry or physics. The controlling habit is not mere abstraction; it is disciplined translation between categories until a stable invariant becomes unavoidable.

Deep reading unit

Each case is read as a miniature bridge: object → vector bundle / symbol / moduli space → invariant → computation → theorem → conceptual dictionary.

Inherited page features

The page preserves the Conway/Ahlfors visual idiom and adds the Knuth-style richer controls: searchable corpus, family and strategy filters, click-to-open case details, ranked prevalence, decision tree, source spine, and demonstrations.
